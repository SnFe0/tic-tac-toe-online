# Крестики‑нолики — онлайн‑мультиплеер

Браузерная игра в крестики‑нолики в реальном времени с WebSocket‑сервером. Поддерживает несколько игровых комнат одновременно, защиту паролем и мгновенный обмен ходами.

![Node.js](https://img.shields.io/badge/Node.js-18%2B-339933?logo=node.js&logoColor=white)
![WebSocket](https://img.shields.io/badge/WebSocket-ws-blue)
![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

## Технологии

| Слой | Технология |
|---|---|
| Сервер | Node.js, `http` (встроенный), `ws` |
| Клиент | Vanilla JS, WebSocket API |
| Стили | CSS (glassmorphism, CSS‑переменные, анимации) |
| Шрифт | Google Fonts — Orbitron |

---

## Возможности

- Создание комнаты с произвольным названием и опциональным паролем
- Список доступных комнат в реальном времени
- Случайное распределение символов (X / O) при каждой партии
- Рестарт партии без выхода из комнаты
- Уведомление, когда соперник покидает комнату
- Полностью кастомный UI без зависимостей от фреймворков

## Установка и запуск

### Требования

- **Node.js** v18 или новее
- **npm**

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/SnFe0/tic-tac-toe-online.git
cd tic-tac-toe-online

# 2. Установить зависимости
npm install

# 3. Запустить сервер
node server.js
```

Откройте браузер по адресу **http://localhost:8000**.

Чтобы сыграть с другим человеком в локальной сети, откройте `http://<ваш_IP>:8000` на втором устройстве.

### Порт

По умолчанию используется порт `8000`. Чтобы изменить его, задайте переменную окружения:

```bash
PORT=3000 node server.js
```

## WebSocket‑протокол

### Клиент → Сервер

| `type` | Поля | Описание |
|---|---|---|
| `roomList` | — | Запрос списка комнат |
| `join` | `roomId`, `password` | Создать или войти в комнату |
| `move` | `roomId`, `index` (0–8) | Сделать ход |
| `restart` | `roomId` | Запросить перезапуск партии |
| `leave` | `roomId` | Покинуть комнату |

### Сервер → Клиент

| `type` | Поля | Описание |
|---|---|---|
| `roomList` | `rooms[]` | Актуальный список комнат |
| `joined` | `roomId`, `symbol` | Подтверждение входа, назначенный символ |
| `wait` | — | Ожидание второго игрока |
| `state` | `board`, `turn` | Текущее состояние доски и чей ход |
| `end` | `board`, `winner`/`draw` | Конец партии |
| `opponentLeft` | — | Соперник покинул комнату |
| `left` | — | Подтверждение выхода из комнаты |
| `error` | `msg` | Ошибка (неверный пароль, комната заполнена) |
| `info` | `msg` | Информационное сообщение |

## Деплой

Проект можно развернуть на любом сервере с Node.js. Примеры платформ:

- **Railway** — `railway up`
- **Render** — тип сервиса Web Service, команда `node server.js`
- **VPS** — рекомендуется запускать через `pm2` или `systemd`

> Если сайт работает за обратным прокси (Nginx, Caddy), убедитесь, что проброшены заголовки `Upgrade` и `Connection` для WebSocket.
